## Pre-existing failures found (reported, not fixed)

- `go test ./...` fails on `ThroneCore` because `core/server/gen/*.pb.go` is generated by
  `script/build_go.sh` and `protoc` is not installed here. A fresh clone cannot build the Go core
  without protoc — expected, but worth a README note.
- `core/server/internal/boxdns/winipcfg/winipcfg_test.go` uses `%w` in `t.Errorf`, which Go 1.24+
  rejects at vet time. The package fails to compile under `go test` on Go 1.26.5. Pre-existing on
  `HEAD`; unrelated to this cleanup.
